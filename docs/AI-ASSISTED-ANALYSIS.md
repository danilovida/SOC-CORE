# SOC CORE — AI-Assisted Security Analysis

SOC CORE treats AI as an **analyst support capability**, not as an unquestioned decision-maker.

## Appropriate Uses

AI-assisted workflows may support:

- incident summarization;
- enrichment interpretation;
- analyst-facing explanations;
- triage assistance;
- contextual grouping;
- recommended investigation steps;
- conversion of structured telemetry into readable narratives.

## Human Oversight

Security actions with meaningful operational impact should remain subject to deterministic controls, authorization requirements and human validation where appropriate.

## Guardrails

AI-assisted processing should account for:

- prompt injection risk;
- untrusted external content;
- hallucinations;
- data minimization;
- sensitive information handling;
- model access controls;
- auditability;
- deterministic validation before automated actions.

## Principle

AI should reduce analyst workload and improve context without becoming a hidden source of unreviewed authority.
