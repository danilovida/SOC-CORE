# SOC CORE — GitHub Traffic Dashboard

**Status:** Awaiting first GitHub Actions collection.

The scheduled workflow collects GitHub's available rolling 14-day traffic history and updates this page daily.

[Run the first collection manually](https://github.com/danilovida/SOC-CORE/actions/workflows/traffic-analytics.yml) using **Run workflow** on the `main` branch.

Once run, this page will display views, unique visitors, clones, referrers, popular pages, and daily history. GitHub does not disclose visitor identities or traffic older than its available window.
