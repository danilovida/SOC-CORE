# Security Policy

## Reporting a Security Issue

Do not publish sensitive vulnerability details in a public issue.

If you identify a security concern related to SOC CORE public materials, contact the project maintainer privately through an appropriate GitHub-supported private channel where available.

## Scope

This repository primarily contains public documentation and sanitized examples.

Security reports may include:

- accidental exposure of sensitive information;
- unsafe example configurations;
- documentation that could materially weaken a deployment;
- secrets or identifiers committed unintentionally.

## Important

Do not include real credentials, private keys, tokens, customer information or confidential incident data in public reports.
